# Список задач (To-Do List)

Небольшое клиентское приложение на русском языке: список задач, который сохраняется
в браузере между перезагрузками. Без backend, без сборщика и без runtime-зависимостей.

## Функции

1. Добавление задачи.
2. Отметка выполненной и возврат в активное состояние тем же контролом.
3. Удаление конкретной задачи.
4. Сохранение задач и статусов после перезагрузки страницы.

Дополнительно реализованы качества, а не новые функции: пустое состояние, защита от
пустого ввода, обработка ошибок хранилища, адаптивность и доступность с клавиатуры.

## Технологии

| Область | Решение |
| --- | --- |
| Разметка | HTML5, один `index.html`, разметка задачи в `<template>` |
| Стили | CSS3 без препроцессоров, ITCSS (Settings → Generic → Elements → Objects → Components) + BEM |
| Шрифт | Inter 4.1 (SIL OFL 1.1), локально в `fonts/`, без внешних запросов |
| Логика | Vanilla JavaScript, нативные ES Modules, MVC-lite + Repository |
| Хранение | `localStorage`, доступ только из Repository |
| Тесты | Playwright Test (`@playwright/test`) |
| Dev-сервер | `http-server` (единственная devDependency кроме Playwright) |

## Типографика

Гарнитура — **Inter 4.1**, подключена локально из `fonts/` (начертания 400, 500, 600,
сабсеты кириллицы и латиницы, ~77 КБ в репозитории). Лицензия — SIL OFL 1.1, текст
лицензии лежит рядом со шрифтом в `fonts/OFL.txt`. Внешних запросов и CDN нет: для
русского интерфейса браузер грузит только три кириллических файла (~37 КБ), латинский
сабсет подгружается по требованию. Системный fallback — с метриками, согласованными с
Inter, поэтому подмена шрифта не сдвигает вёрстку.

Шкала кеглей 12 / 14 / 16 / 28 px (единственный заголовок — `h1`), интерлиньяж 1.15–1.5,
трекинг −0.02em только у крупного заголовка, подпись поля ввода — микро-лейбл прописными.
Шрифты исходного референса (PP Neue Montreal) не подключены: лицензия не подтверждена.
Решения и границы переноса описаны в `docs/design-system.md` и
`docs/typography-uprock-review.md`.

## Структура

```text
index.html                  разметка, подключение слоёв CSS, preload шрифта, <template>

css/settings/fonts.css      @font-face, локальное подключение Inter
css/settings/tokens.css     дизайн-токены
css/generic/reset.css       минимальный reset

css/objects/app-layout.css  композиция страницы
css/components/*.css        кнопки, поля, форма, список, строка задачи

js/tasks/task-model.js      чистые операции над задачами
js/tasks/task-view.js       DOM, рендер, сообщения, фокус

```

## Требования к окружению

- Node.js 22 LTS (проверено на `22.23.5`), npm `10.9.9`.
- Chromium для Playwright устанавливается отдельно.

## Запуск

```bash
npm ci                            # воспроизводимая установка по package-lock.json
npx playwright install chromium   # один раз, для тестов
npm run serve                     # http://127.0.0.1:4173
```

`npm ci` ставит ровно те версии, что зафиксированы в `package-lock.json`, и падает
при расхождении с `package.json`. Менять зависимости (тогда используется
`npm install <пакет>@<версия>`) нужно только вместе с осознанным обновлением lock-файла.

Приложение нужно открывать через HTTP-сервер, а не через `file://`: ES-модули
блокируются на `file:`, а `crypto.randomUUID()` доступен только в secure context
(`localhost` и `127.0.0.1` считаются доверенными origin).

## Тестирование

```bash
npm test
```

Конфигурация — `playwright.config.js`: Chromium, `testDir: ./tests/e2e`,
`baseURL: http://127.0.0.1:4173`, запуск сервера через `webServer`. Каждый тест
получает новый `BrowserContext`, поэтому `localStorage` изолирован без
дополнительной очистки.

## Ограничения `localStorage`

- Данные привязаны к origin и браузеру: другая схема/порт/браузер — другой список.
- Объём ограничен квотой браузера (обычно около 5 МБ на origin); при переполнении
  запись отклоняется, приложение сообщает об этом и сохраняет задачи в памяти.
- Приватная сессия очищает данные при закрытии последней приватной вкладки, а часть
  браузеров выдаёт нулевую квоту — тогда сохранение недоступно.
- Если пользователь запретил сайту сохранять данные или открыл страницу с `file:`,
  доступ к хранилищу может быть заблокирован (`SecurityError`).
- Повреждённые данные не перезаписываются при запуске: приложение показывает
  восстановимые задачи и сообщение, а запись происходит только по действию пользователя.
- Синхронизации между устройствами нет.

## Об AI-инструменте

Проект реализован AI-агентом (Freebuff, модель DeepSeek V4.1 Flash) в паре
с пользователем: агент писал код, конфигурацию, тесты и документацию, пользователь
утверждал архитектурные и UI-решения. Git, GitHub и публикация выполняются
пользователем. Тесты, контрасты и размеры зон нажатия проверены фактическим
прогоном, а не заявлены.
