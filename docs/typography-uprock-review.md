# Разбор типографики uprock.ru и перенос решений в To-Do List

Документ фиксирует внешний типографический референс, из которого в проект перенесены
конкретные решения, и границы переноса. Задача разбора — не скопировать типографику
маркетингового сайта, а взять из неё приёмы, уместные в коротком одностраничном
интерфейсе из четырёх функций.

**Источник:** главная страница `https://www.uprock.ru` (Webflow), файл
`uprock.webflow.shared.b929ef6db.css` и разметка страницы.
**Дата разбора:** 2026-11-13.
**Реализация:** `css/settings/fonts.css`, `css/settings/tokens.css`,
`css/elements/base.css`, `css/components/task-form.css`, `fonts/`; правила — в
`docs/design-system.md`; проверка — в `tests/e2e/tasks.spec.js` (блок «типографика»).

## 1. Что есть на uprock.ru

**Гарнитура:** Inter (подгружаются начертания 300–700), fallback `sans-serif`. Второй шрифт
— Bebas Neue — используется только в промо-баннере.

**База:** `body` — `1rem / 1.2`, начертание 400.

**Шкала (десктоп → мобайл):**

| Роль | Кегль | letter-spacing | line-height | Начертание |
| --- | --- | --- | --- | --- |
| Display-заголовок hero | 80 → 55 px | −0.07em | 1 | 500 |
| Заголовок секции (`h2`) | 45 → 30 px | −0.05em | 1.05 | 500 |
| Заголовок карточки | 25 → 18 px | −0.05em | 1.2 | 500 |
| Текст карточки, описание | 16 → 14 px | −0.05em | 1.3 | 400 |
| Кнопка | 18 px | −0.05em | — | 500 |
| Микро-лейбл (тег, цена) | 12 px | −0.05em | 0.9–1 | 600, `uppercase` |

**Три системных паттерна референса:**

1. Плотный отрицательный трекинг: −0.05em на тексте 16 px, −0.07em на дисплее.
2. Начертание 500–600 вместо 700: 700 встречается только у Bebas Neue.
3. Три уровня интерлиньяжа: 1.0–1.05 для дисплея, 1.2 для подзаголовков, 1.2–1.4 для текста.

### 1.1. Как референс подключает шрифт

В CSS сайта Inter нет вообще — ни одного `@font-face` для него. Гарнитура подключена
скриптом в `<head>`:

```html
<link href="https://fonts.googleapis.com" rel="preconnect"/>
<link href="https://fonts.gstatic.com" rel="preconnect" crossorigin="anonymous"/>
<script src="https://ajax.googleapis.com/ajax/libs/webfont/1.6.26/webfont.js"></script>
<script>WebFont.load({ google: { families: ["Inter:300,400,500,600,700"] } })</script>
```

Что из этого следует:

- отдельного `<link>` на `fonts.googleapis.com/css?family=Inter…` на странице нет
  (проверено: 0 совпадений) — CSS подставляет сам WebFont.js;
- WebFont.js асинхронно подключает CSS Google Fonts, в ответе которого **35 блоков
  `@font-face`**: 5 начертаний × 7 сабсетов (cyrillic, cyrillic-ext, latin, latin-ext,
  greek, greek-ext, vietnamese);
- `font-display` в ответе v1-API Google Fonts **не задан**, поэтому действует значение
  по умолчанию `auto`: до ~3 с текст держится невидимым, затем подменяется шрифтом;
- в CSS задан только `font-family: Inter, sans-serif` — родовой fallback **без**
  `size-adjust`/`ascent-override`, поэтому при подмене шрифта метрики прыгают;
- фактический вес: браузер тянет только нужные сабсеты — около 18 КБ на начертание за
  кириллицу и около 48 КБ за латиницу;
- второй шрифт (Bebas Neue) подключён иначе — self-hosted `.otf` с CDN Webflow и
  `font-display: swap`, то есть ровно тот подход, которого не хватает Inter.

## 2. Что было в проекте до разбора

Системное семейство, кегли 14 / 16 / 18 / 28 px, интерлиньяж 1.5 (текст) и 1.2 (заголовки),
начертания 400 / 500 / 700, трекинг `-0.01em` только у `h1`.

## 3. Перенесено в проект

| # | Решение uprock.ru | Что сделано в проекте | Обоснование |
| --- | --- | --- | --- |
| A1 | Заголовки не жирнее 500–600 | `h1`: начертание `700 → 600` | Наш заголовок — 28 px; 600 даёт «дизайнерскую» плотность без потери читаемости. Токен 700 удалён как неиспользуемый |
| A2 | Плотный трекинг крупного текста | `h1`: трекинг `-0.01em → -0.02em` | У uprock на дисплее −0.07em, на h1 −0.04em; для наших 28 px взята половина, чтобы не «схлопнуть» буквы |
| A3 | Плотный интерлиньяж заголовков | `h1`: интерлиньяж `1.2 → 1.15` | У uprock 1.0–1.05. Ниже 1.15 не опускаем: в русском «Д», «Щ», «р» клипуются |
| A4 | Микро-лейбл из 12 px / 600 / `uppercase` | Подпись поля ввода: `uppercase`, 12 px, начертание 600 | Даёт недостающий уровень иерархии без новых элементов и без изменения текста в DOM |
| A5 | Гарнитура Inter | Подключена локально: `css/settings/fonts.css` + `fonts/`, начертания 400 / 500 / 600 | Гарнитура референса метрически стабильна и имеет кириллицу; лицензия Inter — SIL OFL 1.1, ограничений на использование нет |

Вспомогательные токены: `--font-size-xs`, `--font-weight-semibold`, `--line-height-heading`,
`--letter-spacing-heading`.

## 4. Осознанно не перенесено

| Приём uprock.ru | Почему не берём |
| --- | --- |
| Трекинг −0.05em на тексте 16 px | На кириллице отрицательный трекинг сплющивает межсловные интервалы и снижает разборчивость |
| Трекинг −0.07em и −0.08em | Дисплейных кеглей в проекте нет: максимум 28 px |
| Bebas Neue, кегли 45–80 px | Приём витрины, а не рабочего интерфейса |
| Интерлиньяж 0.9 у микро-лейблов | Клип верхних и нижних выносных элементов кириллицы |
| Начертание 300 (26 применений на сайте) | Тонкий текст на светлой поверхности читается хуже |
| `uppercase` для длинных строк | Только короткие микро-лейблы |
| Таблица кеглей × четыре брейкпоинта | Дублирование без пользы: в проекте одна колонка и фиксированная шкала |
| Fluid-тип через `clamp()` | Референс так не делает; в проекте это лишняя сложность без выигрыша |
| Подключение Inter через Google Fonts и WebFont.js | Внешний CDN и скрипт загрузчика, отсутствие `font-display`, fallback без метрик, лишние греческий и вьетнамский сабсеты |

## 5. Отклонения и их причины

- **Интерлиньяж основного текста оставлен 1.5** (у uprock 1.2–1.4). Текст задачи
  набирается в одну колонку, бывает длинным и должен переживать увеличение до 200 %.
- **Трекинг микро-лейбла нормальный**, без отрицательного межбуквенного интервала из
  референса: на кириллических прописных он ухудшает разборчивость.
- **`text-transform` вместо изменения текста.** Текст в DOM остаётся «Новая задача»,
  поэтому доступное имя поля не меняется — это проверено тестом
  «прописная подпись не меняет текст в DOM и доступное имя поля».
- **Способ подключения шрифта.** Референс грузит Inter с Google Fonts; проект — локально.
  Решение по шрифту принято отдельно от разбора типографики, чтобы не менять зависимости
  молча.

## 6. Как подключён Inter в проекте

- **Источник.** Официальная сборка Inter 4.1 из репозитория rsms/inter, лицензия
  SIL OFL 1.1, текст лицензии — `fonts/OFL.txt` (при распространении шрифта лицензия
  обязательна).
- **Начертания:** 400, 500 и 600 — ровно те, что использует дизайн-система. Первая версия
  подключения брала только 400 и 600, но этого не хватало: кнопки используют вес 500,
  а при наличии только 400 и 600 браузер подставляет 400 (правило подбора веса по CSS
  Fonts) — Medium просто исчез бы. Начертание 700 из референса не переносилось.
- **Нарезка.** На каждое начертание два сабсета: кириллица (~12.5 КБ) и латиница
  (~13 КБ) — 77 КБ на шесть файлов. Сабсет кириллицы включает русскую типографику
  (`« » — … №`), латинский — ASCII и Latin-1.
- **Границы `unicode-range` настроены по фактической загрузке, а не «как в Google
  Fonts».** Первый вариант делил диапазоны по стандартной схеме, и браузер тянул
  латинский файл всегда: русский текст использует ASCII-пробел, запятую и точку
  (U+0020, U+002C, U+002E), которые в схеме Google входят в латинский сабсет.
  Поэтому пробелы, цифры и пунктуация (U+0020–U+003F) отнесены к кириллическому
  сабсету, а латинский объявляет только буквы (U+0041–U+005A, U+0061–U+007A и
  Latin-1). Итог: для русского интерфейса грузятся три кириллических файла (~37 КБ),
  латинский подгружается по требованию, если пользователь введёт латиницу.
- **`font-display: swap`** — текст виден сразу, шрифт подменяется без блокировки.
- **Fallback с согласованными метриками.** По метрикам Inter (upm 2048, ascent 1984,
  descent 494, x-height 1118) и пары Arial / Liberation Sans (upm 2048, ascent 1854,
  descent 434, x-height 1062) посчитаны `size-adjust: 105.273%`,
  `ascent-override: 101.652%`, `descent-override: 108.123%`, `line-gap-override: 0%`.
  Проверено измерением: ширина строки «Список задач — покупка хлеба» кеглем 28 px
  отличается от Inter на **1.37 %** (без overrides был бы разброс ~6.3 %), высота
  строки совпадает точно — то есть скачка вёрстки при подмене шрифта нет.
- **Preload** — только для кириллических сабсетов 400, 500 и 600 (те, что нужны на
  первом экране); латиница догружается по требованию.
- **Сторонних запросов нет** — шрифт лежит в репозитории, проверяется тестом.

## 7. Проверка

- `npx playwright test` — 29 сценариев, все пройдены (включая три сценария блока
  «типографика» и проверку 200 % текста).
- Сценарий «шрифт грузится локально, сторонних запросов нет» проверяет, что все
  запросы страницы идут на собственный origin, что в `font-family` есть `Inter` и что
  кириллические начертания 400 и 600 загружены (`document.fonts.check`).
- Отдельно измерено, что начертания разрешаются корректно: ширина строки «Добавить»
  кеглем 16 px — 76.33 px (400), 77.42 px (500), 78.55 px (600), то есть веса не
  подменяются друг на друга.
- Контрасты не менялись: цвета текста остались прежними, изменены только кегль,
  начертание, интерлиньяж, трекинг и гарнитура. Контраст подписи `#5D6472` к `#FEFEFE` —
  5.90:1, что проходит WCAG 2.2 AA и для обычного текста, и для уменьшенного кегля.
- Визуальная проверка выполнена на отрисованной странице (Chromium, 1280 px и 320 px):
  шрифт Inter применился, переносов и обрезки нет.
